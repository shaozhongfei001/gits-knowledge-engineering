# 市场维度研判

对下游终端需求趋势进行研判：分析市场规模变化（近3年CAGR）、下游景气度（如房地产新开工面积、汽车销量增速）、竞争格局（CR3集中度、进入壁垒），研判标签（扩张/平稳/萎缩），并提炼核心判断依据（如“工程机械行业进入下行周期，需求同比-15%”）。结论由市场慧眼智能体（LLM）基于行业研究报告和公开市场数据分析生成。
