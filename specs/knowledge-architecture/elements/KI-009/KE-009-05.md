# 年营收（近12月）

客户近12个月在行内结算账户累计贷方发生额（含销售回款、政府补贴等经营性收入），作为衡量企业经营规模和现金流能力的基础指标。系统从核心系统接口拉取，展示时附带同比变化百分比。
