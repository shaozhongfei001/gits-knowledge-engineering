# 行动计划

针对每条承诺事项生成的标准化行动建议，包括：①责任人（行内客户经理或客户方对接人）；②截止时间（建议完成日期，基于约定日期倒推提醒）；③具体行动路径（分步骤描述，如“Step1: 8月20日前邮件催促客户准备报告 → Step2: 8月25日电话跟进确认进度 → Step3: 9月1日前更新CRM记录”）。行动计划由规则引擎根据承诺类型和约定时间自动生成初始版本，客户经理可手动编辑后确认。
