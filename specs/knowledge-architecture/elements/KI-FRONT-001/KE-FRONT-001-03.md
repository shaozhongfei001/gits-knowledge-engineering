# 供应链位置解读

综合上游供应商集中度和下游客户分散度，定性评估客户在产业链中的位置角色（如“中游核心制造环节”）、对上下游的议价能力（强/中/弱）、供应链稳定性风险等级（高/中/低）。结论由LLM基于图谱数据和行业知识库综合推理生成，供客户经理快速理解客户在产业生态中的经营地位和风险暴露点。输出结构为三段式：“角色定位 + 议价能力评估 + 供应链稳定性判断”。
