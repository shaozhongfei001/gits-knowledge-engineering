###   你必须理解的业务主链
==================================================

“客户经理持续经营”不是单纯的拜访报告生成场景。

完整业务主链是：

市场慧眼
→ 客户洞察
→ Customer Operating View
→ KYC Gap
→ Visit Mission
→ R1访前作战报告
→ R2 60秒作战卡
→ 产品适配
→ 客户触达/建联
→ 会中Interaction
→ Claim / Intent / Need / Concern抽取
→ Fact Reconciliation
→ 离场确认
→ Commitment
→ Task
→ 访后分析
→ R4 / R5-A / R5-B
→ CRM受控写回
→ 专业协同
→ 新Evidence
→ ClaimAssessment更新
→ R7
→ R8
→ 下一轮客户经营

核心思想是：

一次客户Interaction不能随着CRM纪要结束而结束，
而必须进入下一轮持续经营记忆。
