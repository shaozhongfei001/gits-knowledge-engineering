# PP-D06｜客户没接电话、只回一句“忙”，后面的触达往往靠客户经理自己记

- Priority：P2
- Evidence：E3
- 推荐剧情时间：10:05-10:28
- 推荐页面：PAGE-09

## 真实业务表达
第一次没联系上不代表客户拒绝，什么时候再联系、换什么渠道、上次客户怎么回复，需要连续记忆。

## 剧情
电话未接→微信简短回应→二次说明→确认预约，触达状态连续保留；频控规则待访谈验证。

## 系统解决方向
Channel Memory + Outreach State记录未接/已读/拒绝/延期/预约等状态。

## 需要的数据
触达日志、渠道响应、客户偏好、日历

## 知识 / 对象 / Skill
- 知识：渠道触达规则、频控规则
- 对象：OutreachAttempt, ContactPreference, ResponseState
- Skill：SP-03
- Runtime：RSK-06

## Human Gate / 边界
- Human：RM决定是否再次触达
- No-Go：不能连续自动催促客户

## 验收
需经真实RM访谈和触达制度确认后转正式需求

> 说明：本项为P2，其中E3内容不得在未完成用户访谈/制度确认前写成银行已确认现状。
