# PP-B07｜只看余额或利润，容易把客户价值和经营质量看偏

- Priority：P1
- Evidence：E1
- 推荐剧情时间：08:42
- 推荐页面：PAGE-03

## 真实业务表达
规模大不一定价值高，高成本资金、资本占用和风险也要一起看。

## 剧情
存款下降并不被直接判为客户价值下降；系统同时看结算、授信、关系深度和项目机会。

## 系统解决方向
用规模、利润、资金成本、资本占用、风险质量和关系深度解释客户价值。

## 需要的数据
存贷、FTP、收益、资本、风险、产品、结算

## 知识 / 对象 / Skill
- 知识：客户价值评价口径
- 对象：CustomerValueAssessment, MetricDefinition
- Skill：SP-01；SP-12
- Runtime：RSK-01, RSK-20

## Human Gate / 边界
- Human：RM/主管确认经营策略
- No-Go：不能以单一余额/考核利润决定经营级别

## 验收
结论说明指标口径、时点和限制
