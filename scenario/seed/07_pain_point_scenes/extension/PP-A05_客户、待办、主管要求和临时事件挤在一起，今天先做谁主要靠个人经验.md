# PP-A05｜客户、待办、主管要求和临时事件挤在一起，今天先做谁主要靠个人经验

- Priority：P1
- Evidence：E3
- 推荐剧情时间：08:35
- 推荐页面：PAGE-01

## 真实业务表达
一天里既有重点客户、续授信、临时电话、逾期任务，也有领导刚下来的要求，真正麻烦的是排序。

## 剧情
多个客户、续授信、临时电话和主管要求同时出现；系统提出可解释排序，但规则仍需真实RM访谈验证。

## 系统解决方向
设计可解释的RM Day Plan，将经营机会、正式任务、承诺到期和临时事件统一排程。

## 需要的数据
CRM任务、客户承诺、日程、机会时效、主管任务

## 知识 / 对象 / Skill
- 知识：日常作业规则、任务优先级规则
- 对象：Task, Commitment, VisitPlan, PriorityReason
- Skill：SP-01
- Runtime：RSK-01, RSK-04

## Human Gate / 边界
- Human：RM调整顺序并保留原因
- No-Go：AI不能替RM/主管自动改正式任务优先级

## 验收
先经真实RM访谈确认排序因素后再转正式需求

> 说明：本项为P1，其中E3内容不得在未完成用户访谈/制度确认前写成银行已确认现状。
