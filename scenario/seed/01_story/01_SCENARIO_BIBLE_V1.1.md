# 华东精工客户经理持续经营场景圣经 V1.1

## 1. 场景定位

这个场景不是“AI生成一份拜访报告”，而是复现一个对公客户经理从早上到晚上的真实经营过程：机会很多、系统很多、客户表达不清、专业规则复杂、会后录入繁重，但经营上下文必须不断线。

主线：
`岗位角色 → 业务场景 → Skill能力 → 知识资产 → 平台能力 → 系统嵌入 → 迭代研发`

业务链：
`市场慧眼 → 客户洞察 → KYC/访前 → 产品准备 → 客户触达 → 会中Interaction → Fact Reconciliation → 离场承诺 → 访后分析 → CRM受控写回 → 新Evidence → R7/R8`

## 2. 关键客户事实

- 华东精工与本行合作8年，是合成战略客户。
- 集团综合授信1.5亿元，已用1.1亿元，账面可用4000万元。
- 2026年3月以来本行关系口径的存款由约1.2亿元下降至约7800万元。
- 本行可见设备供应商付款在近期明显增加，但不代表客户全量设备付款。
- 外部出现智能制造二期项目备案，备案总投资约4800万元。
- 客户后续发送设备清单初稿，设备金额3280万元。
- 客户说“希望银行增加3000万左右支持”，但最终澄清为第一阶段设备款资金安排，不能自动认定新增授信。

## 3. 本版与V1.0最大的不同

V1.0证明机制能跑；V1.1要求**27个P0痛点都在剧情里发生**，每个痛点都有真实数据、对话、页面、Skill调用、Human Gate和验收。

## 4. 生产边界

本场景所有数据为合成演示。客户现场在剧情中**不授权全程录音**，因此生产输入使用“现场笔记+访后口述”；`meeting_gold_transcript.txt`只作为测试Gold Standard，不代表生产系统真的取得该录音。
